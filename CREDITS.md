All models are procedurally generated in code (original). Any CC0 assets added later will be listed here with source URL and license.

## Character and ship designs

The hunter, helmet, and ship are fan-homage designs inspired by the animated Star Wars series (armored Mandalorian-style hunter, chrome starfighter silhouette). They are built entirely from code primitives; no models, textures, or likenesses were copied.

## Audio

All sound effects and the placeholder music are synthesized at runtime with the Web Audio API (original). No recorded samples.
